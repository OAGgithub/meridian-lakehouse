# ops schema reference

## meridian.ops.load_run

| column | type | notes |
| --- | --- | --- |
| `run_id` | STRING | uuid4, generated by the caller before the INSERT |
| `source_name` | STRING | e.g. `core_banking`, `account_master`, `fred` |
| `source_type` | STRING | `file` \| `jdbc` \| `api` |
| `source_object` | STRING | file path, table name, or endpoint |
| `target_table` | STRING | three-level name |
| `load_date` | DATE | the business date being loaded, not today |
| `started_at` | TIMESTAMP | UTC |
| `finished_at` | TIMESTAMP | UTC, NULL while running |
| `status` | STRING | running / succeeded / failed / partial |
| `rows_read` | BIGINT | from the source |
| `rows_loaded` | BIGINT | written to target |
| `rows_rejected` | BIGINT | read but not written |
| `error_message` | STRING | NULL unless failed |
| `triggered_by` | STRING | `manual` \| `job` \| `backfill` |

`rows_read = rows_loaded + rows_rejected` must hold. If it does not, the
counting is wrong — do not paper over it.

## meridian.ops.dq_result

| column | type | notes |
| --- | --- | --- |
| `run_id` | STRING | joins to load_run |
| `check_name` | STRING | stable identifier, e.g. `txn_id_not_null` |
| `check_target` | STRING | three-level table name the check ran against |
| `severity` | STRING | `error` \| `warn` |
| `passed` | BOOLEAN | |
| `observed_value` | STRING | what was found |
| `expected_value` | STRING | what was required |
| `detail` | STRING | free text, optional |
| `checked_at` | TIMESTAMP | UTC |

## Shape of a load

```python
run_id = str(uuid.uuid4())
start_run(run_id, source_name="core_banking", source_type="file",
          source_object=str(path), target_table="meridian.bronze.transactions",
          load_date=business_date, triggered_by="manual")
try:
    rows_read, rows_loaded, rows_rejected = land(path)
    record_check(run_id, "row_count_positive", "meridian.bronze.transactions",
                 severity="error", passed=rows_loaded > 0,
                 observed_value=str(rows_loaded), expected_value="> 0")
    status = "partial" if rows_rejected else "succeeded"
    finish_run(run_id, status, rows_read, rows_loaded, rows_rejected)
except Exception as exc:
    finish_run(run_id, "failed", error_message=repr(exc))
    raise
```

The `raise` is required. A pipeline that logs a failure and then exits 0
will be scheduled, will fail nightly, and nobody will know.
